# academic-style

降低中文学术写作AIGC检测率的专项工具。

## 简介

本工具基于AI写作模式识别与真实学者风格迁移，实现逐句改写并输出AIGC评分。降低AIGC检测率的关键在于使文本既保持学术严谨性，又体现自然写作的多样性。AI写作的规律性主要体现在结构过度对称、表达模式化、结论泛化等特征；而高质量学术写作则应在保持逻辑严密性的同时，体现论证的层次性和表达的多样性。

## 核心功能

- **AI模式识别**：扫描16种典型AI写作模式（内容、语言、风格三个层面）
- **AIGC评分**：基于命中模式数量计算AIGC率，量化AI痕迹
- **自动重写**：AIGC率过高时自动触发重写（最多3次）
- **学者气质注入**：改写时加入真实学者的主观表达、意外发现和局限承认
- **语料微调**：支持@引用个人写作样本，提取风格特征实现个性化改写

## 快速开始

### 基本用法

```
@academic-style/SKILL.md
句子：多线程环境下，共享资源的访问需要同步机制来保证数据一致性。
领域：计算机技术
强度：auto
```

### 带个人语料（可选）

```
@academic-style/SKILL.md @语料/我的论文.md
句子：多线程环境下，共享资源的访问需要同步机制来保证数据一致性。
领域：计算机技术
强度：auto
```

## 参数说明

| 参数 | 必填 | 类型 | 默认值 | 说明 |
|---|---|---|---|---|
| `text` | 是 | string | - | 待改写的语句或段落 |
| `domain` | 否 | string | "计算机技术" | 论文领域 |
| `intensity` | 否 | string | "auto" | 改写强度：轻度/中度/深度/auto |

## AIGC评分机制

```
AIGC率 = (命中模式数量 / 16) × 100%
```

| AIGC率 | 风险等级 | 处理方式 |
|---|---|---|
| ≤30% | 低AI风险 | 直接输出 |
| 30%-50% | 中AI风险 | 输出并提示可进一步优化 |
| >50% | 高AI风险 | 自动触发重写（最多3次） |

## 16种AI写作模式

本工具识别并修复以下典型AI写作模式：

**内容层面**
- 模式1：「依据/基于XX理论」起笔模式
- 模式2：「此案例印证了/挑战了/揭示了」段末套路
- 模式3：「基于N重考量：首先/其次/再次」编号逻辑
- 模式4：「该处理体现了/该设计基于」被动分析套话
- 模式5：「译者/研究者面临的核心问题是」模板化问题陈述
- 模式6：高度对称的三元并列句式
- 模式7：段末画蛇添足的总结句
- 模式8：模糊归因
- 模式9：填充短语与过度限定
- 模式10：泛化结论与「具有重要意义」结尾

**语言层面**
- 模式11：中文AI高频词汇
- 模式12：主动回避「是」的系动词替换
- 模式13：过度对仗的排比结构
- 模式14：结构性分析的「三步走」模式

**风格层面**
- 模式15：「——」破折号滥用（或完全不用）
- 模式16：加粗滥用

## 系统响应示例

**低AI风险（AIGC率≤30%）：**
```
改写结果：多线程环境下，共享资源的访问需要同步机制。引入锁机制——通过原子操作和内存屏障，可以有效解决数据竞争问题。

AIGC评分：12.5%（低AI风险）
命中模式：模式9（填充短语）
重写次数：1/3
```

**高AI风险（AIGC率>50%，触发重写）：**
```
改写结果：系统的最终行为或输出，依赖于多个事件发生的相对顺序...

AIGC评分：62.5%（高AI风险，已触发自动重写）
命中模式：模式1、模式2、模式3...
重写次数：3/3（已达上限，建议手动优化剩余模式）
未修复模式：模式1、模式11
```

## 扩展性

- **语料微调**：@引用个人写作样本，提取风格特征实现个性化改写
- **风格规则自定义**：可在SKILL.md中修改风格特征描述，添加自定义改写规则
- **领域适配**：预设多个领域的术语库，支持添加领域专属术语
